# Mini Vite React Interface

This repository contains a **small frontend interface built with Vite, React, and TypeScript**.

It is **not a standalone project**.  
It is intended to be used as a **minimal UI** for other repositories (backend, APIs, experiments, etc.).

The goal is to provide a **simple and lightweight interface** that can be reused or adapted easily.

## Tech stack
- Vite
- React
- TypeScript
